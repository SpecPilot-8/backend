# 한국어 OCR 실행 환경

화면 헤더의 한글이 PDF 텍스트가 아닌 도형으로 들어 있어 한국어 OCR 데이터가 필요합니다. Tesseract는 kor가 없어도 영문 인식을 계속할 수 있으므로, 파서는 필요한 언어 데이터가 없으면 빈 값과 검토 경고를 남기고 영문 인식으로 대신하지 않습니다.

- Tesseract 및 `kor.traineddata`, `eng.traineddata`를 준비합니다. 언어 파일은 공식 tessdata 저장소에서 받을 수 있습니다: https://github.com/tesseract-ocr/tessdata_fast
- `TESSDATA_PREFIX`로 데이터 폴더를 지정합니다. 별도 환경변수가 없으면 backend/.data/tessdata의 두 파일을 사용합니다. `.data`는 Git에 올리지 않습니다.
- 데이터 준비 후 ‘문서 다시 파싱’을 눌러 기존 잘못된 헤더를 다시 읽습니다. 저장된 요구사항이 출처 블록을 참조 중이면 새 문서로 등록해야 합니다.
- 한국어 데이터가 있어도 OCR 오독 가능성은 남으므로 경고를 삭제하거나 고신뢰도 텍스트를 확정값으로 처리하지 않습니다. 빈 설명 표가 있는 상태 화면도 원문 확인 대상으로 남깁니다.

2026-10-26 로컬 예시 PDF 15쪽 재검증: 695블록, 읽지 못한 페이지 0. 한글 Depth가 ‘통합 로그인’, ‘공지 사항 관리’로 복원됐습니다. 마이페이지 헤더의 ‘파 이/마 이’ 오독 차이는 원문 확인이 필요합니다. 기존 경고 23건은 15건(12쪽의 OCR 원문 대조 + 3쪽의 빈 설명 표 검토)으로 줄었습니다.
