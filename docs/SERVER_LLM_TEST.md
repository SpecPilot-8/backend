# 서버 고정 LLM 연결 테스트

현재는 backend/.env의 `SPECPILOT_LLM_PROVIDER`, `SPECPILOT_LLM_MODEL`, 제공업체 키로 테스트한다. Anthropic은 `ANTHROPIC_API_KEY`, Vercel은 `AI_GATEWAY_API_KEY`를 사용한다. 키는 Git이나 채팅에 올리지 않는다. 기존에 등록한 키를 다시 입력할 필요 없다.

1. 백엔드를 `.env`와 함께 실행하거나 설정 변경 후 재시작한다.
   `python -m uvicorn api.main:app --host 127.0.0.1 --port 8000 --env-file .env --reload`
2. 프론트 프로젝트 설정 화면을 새로고침한다.
3. 프로젝트 이름을 입력해 설정을 저장한다. 연결 검사에는 문서·ZIP이 필요하지 않다.
4. ‘AI 모델 연결’ 카드에 서버의 제공업체와 모델이 표시되는지 확인한다.
5. ‘실제 연결 확인’을 누른다. 짧은 고정 프롬프트 1회에 비용이 발생할 수 있다. 문서·코드는 전송하지 않는다.
6. ‘연결 완료’가 표시되면 선택 모델의 실제 호출과 JSON 응답 검증이 성공한 것이다. 저장한 프로젝트를 다시 열어도 결과를 조회할 수 있다.

키/모델/제공업체가 바뀌면 이전 성공을 사용하지 않는다. 키가 없거나 미지원 제공업체면 버튼이 비활성화된다. 호출 실패는 인증·모델/권한·요청 제한·크레딧·시간 초과 등 안전한 오류로 표시한다.

## 범위와 남은 작업

연결 검사는 자동 분석 파이프라인의 완료를 의미하지 않는다. 문서 업로드·원문 파싱·코드 인덱싱·수동 요구사항/시험 편집·Excel 내보내기는 기존 기능을 사용한다. 웹 자동 요구사항 추출(#49), 코드 판정(#50), 테스트 생성(#51), 장시간 작업 실행(#52)은 별도 연결이 필요하다. 현재 blocked 응답을 성공으로 바꾸거나 AI 결과를 임의 생성하지 않는다.

프로젝트별 사용자 키 저장·여러 제공업체/모델 연결은 #48의 미완료 범위와 #76에서 추적한다. 인증/프로젝트 권한(#53) 완료 전에는 신뢰하는 로컬 개발 환경에서 사용한다.
